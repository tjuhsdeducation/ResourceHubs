  1. Open the master Google Sheet → Extensions → Apps Script.
  2. Click Deploy → Manage deployments. Click your Web app deployment and copy the Web app URL. It ends in /exec.
    No deployment listed? Use Deploy → New deployment → ⚙ Web app, Execute as Me, Who has access Anyone.

4. On GitHub, open hub-config.js → ✏️ Edit. Select everything, delete it, and paste this whole box. Then Commit changes. (Your schools and teachers are kept.)
